# Fuel Ledger — دفتر حركة الوقود

تطبيق عربي متجاوب لإدارة حركة الوقود اليومية والشهرية في محطة وقود، مبني بـ React وVinext ويستخدم قاعدة بيانات SQLite متوافقة مع Cloudflare D1.

## الوظائف

- صفحة يومية مستقلة لكل يوم مع قالب جاهز تلقائيًا.
- ترحيل قراءة غلق اليوم السابق ورصيد نهايته إلى اليوم التالي.
- إعداد المسدسات وأرقام بدايتها لكل شهر، بدون إعداد سعة الخزانات.
- تسجيل الوارد والقراءات والعيارات؛ العيارات تعود دائمًا إلى الرصيد.
- ملخص يومي وشهري منفصل للسولار وبنزين 92.
- لا يوجد حقل «صافي المنصرف».
- حفظ دائم للبيانات مع منع تعارض الحفظ بين الجلسات.
- واجهة عربية RTL متجاوبة مع الهاتف.
- تنزيل واستيراد نسخة احتياطية بصيغة JSON.

## التشغيل محليًا

يتطلب Node.js 22 أو أحدث.

```bash
npm run install:ci
npm run dev
```

## الاختبارات والبناء

```bash
npm test
npm run build
```

## البنية

- `app/ledger/`: واجهة التطبيق وحسابات الحركة.
- `app/api/ledger/`: واجهة حفظ وقراءة الدفتر.
- `db/schema.ts`: مخطط قاعدة البيانات.
- `drizzle/`: ترحيلات SQLite/D1.
- `tests/`: اختبارات الحسابات والواجهة والبناء.
